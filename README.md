# My Portfolio

เว็บไซต์พอร์ตโฟลิโอส่วนตัวของ นาย นราวิชญ์ ขันทะสา นักศึกษาชั้นปีที่ 4 สาขานวัตกรรมธุรกิจดิจิทัล (DBI) คณะบริหารธุรกิจ มหาวิทยาลัยแม่โจ้

🔗 **Live Demo:** [my-portfolio-ochre-delta-42.vercel.app](https://my-portfolio-ochre-delta-42.vercel.app)

## เกี่ยวกับเว็บไซต์นี้

พอร์ตโฟลิโอออนไลน์สำหรับนำเสนอข้อมูลส่วนตัว การศึกษา ทักษะ ประสบการณ์ทำงาน ผลงานโปรเจกต์ และใบรับรองต่าง ๆ เพื่อใช้ประกอบการสมัครงานและฝึกงานสาย AI/Automation

## เนื้อหาในเว็บไซต์

- **About Me** — ข้อมูลเบื้องต้นและความสนใจด้าน Data Analysis, Business Intelligence, AI Automation
- **Education** — ประวัติการศึกษา
- **Skills** — Hard Skill (n8n, Supabase, Gemini AI, Figma) และ Soft Skill
- **Experience** — ประสบการณ์เก็บข้อมูลงานวิจัยร่วมกับมหาวิทยาลัยขอนแก่นและมหาวิทยาลัยหาดใหญ่
- **Project** — ผลงานโปรเจกต์ เช่น AI Assistant for Line Activity Notification, App RecycleHere
- **Certificate** — ใบรับรองการอบรม n8n, Make.com, Git & GitHub
- **Contact** — ช่องทางการติดต่อ
